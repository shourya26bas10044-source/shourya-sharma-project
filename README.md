# 🧮 ADVANCED MATHEMATICS CALCULATOR

## 📌 Project Description

The **Advanced Mathematics Calculator** is a menu-driven Python program designed to perform a wide range of mathematical calculations using simple Python programming concepts.

The project follows the basic principle:

**INPUT → PROCESS → OUTPUT**

It is designed for students to understand how mathematical concepts can be implemented using Python **without relying on external libraries or modules**.

## 🧠 Mathematical Methods Used

The project implements several mathematical algorithms manually.

### Square Root
Uses the **Newton-Raphson method**.

### Exponential
Uses a **Taylor series**.

### Polynomial Evaluation
Uses **Horner's method**.

### Polynomial Roots
Uses:
- Linear formula
- Quadratic formula
- Numerical methods for higher-degree equations

### Function Root
Uses the **Newton-Raphson method**.

### Matrix Determinant
Uses recursive **cofactor/minor expansion**.

### Matrix Inverse
Uses the **Gauss-Jordan elimination method**.

### Statistics
The median calculation uses **Bubble Sort**.

### Number Conversion
Binary, octal and hexadecimal conversions are implemented manually rather than using Python's built-in `bin()`, `oct()` and `hex()` functions.

## ▶️ How to Run

### Step 1: Install Python

Install Python 3.x on your computer.

### Step 2: Save the Program

Save the source code as:

```text
ADVANCED MATHEMATIC CALCULATOR.py
```

### Step 3: Run the Program

Open Command Prompt or Terminal and use:

```bash
python "ADVANCED MATHEMATIC CALCULATOR.py"
```

Or open the file directly using **IDLE** and select:

```text
Run → Run Module
```
